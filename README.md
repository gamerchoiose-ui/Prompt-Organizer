# Prompt Organizer

Prompt Organizer is a web application that helps users organize,
store, search, and manage AI prompts efficiently.

## Features

- Create and manage prompts
- Organize prompts by category
- Search prompts
- Edit and delete prompts
- Responsive user interface

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
git clone https://github.com/gamerchoiose-ui/Prompt-Organizer.git
cd Prompt-Organizer
npm install
npm run dev
